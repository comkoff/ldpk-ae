2.1.6&jacobian; and twist vector In this section we document the evaluation of &jacobian; and twist vector. Both quantities are defined in unit-coordinates and based on the undistort-function. The &jacobian; is of interest if your are building a compositing operator for (un-)distorting images based on a grid warp (like e.g. Nuke's GridWarp node). Sophisticated grid warp operators allow to specify the grid vertices and the two tangent vectors at the grid vertex positions along the grid lines. The &jacobian; directly relates to these tangent vectors.

Distortion model classes are not obliged to provide an implementation for the &jacobian; or the twist vector. There are methods


getJacobianMatrixDQ(...)
getTwistVectorDQ(...)
which estimate the &jacobian; and the twist vector by means of difference quotients. Generally, the distortion classes shipped with &tde4; are equipped with an implementation of the &jacobian; but not for the twist vector. All methods for estimating the &jacobian; and the twist vector will return None in case the argument does not lie within the domain of undistort(...). This is particularly relevant for non-gnomonic lenses like fisheyes.

The following snippets are a test for 69 in [1]. For our examples we prepare a filmback of 2 &cm; × 1 &cm; and a simple model function:

ldm = ldpk.radial_standard_degree_4()
ldm.w_fb_cm(2.0).h_fb_cm(1.0)
ldm.c2(0.1).prepare()
Now let us have a look at the &jacobian;: 
pretty.out(ldm.getJacobianMatrix((.5,.5)))

In order to do this we specify two filmbacks and lens center offsets and define that these represent to regions in the same focal plane of a hypothetical camera with coincident lens center. Of course, we get different unit coordinates for the two filmbacks. Yet, we can compare the two setups by expressing in- and output of the distortion mapping in length units on the virtual filmback relative to the lens center. For this purpose we implement two functions: 

def unit2cm(ldm,p_unit):
	return (p_unit[0] * ldm.w_fb_cm() - ldm.x_lc_cm(),p_unit[1] * ldm.h_fb_cm() - ldm.y_lc_cm())
def cm2unit(ldm,p_cm):
	return ((p_cm[0] + ldm.x_lc_cm()) / ldm.w_fb_cm(),(p_cm[1] + ldm.y_lc_cm()) / ldm.h_fb_cm())

4.133DE4 Radial - Homomorphic, Degree 2
An experimental model with focus on low number of parameters.
	When decentering is 0, the model has the following properties:
	1. Any two consecutive operations (applying or removing lens distortion
	by parameters a and b can be replaced by a single operation
	by a+b.
	2. As a consequence, removing distortion by some parameter value a
	is exactly the same as applying distortion by a value −d,
	i.e. for each operation there is an exact inverse operation.
	Mathematically speaking the model function (without decentering)
	is a homomorphism from the real numbers to the set of distortion mappings.
