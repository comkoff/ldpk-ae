vec2_type undistort (const vec2_type &p_any_dn) const
 Given a point in diagonally normalized coordinates on a filmback with any of the fisheye models we compute the point position as it would be for a plain mapping function. This is done by mapping the point into an elongation angle (i.e. in 3d space), and then mapping the elongation angle back to the filmback. In this form we do not use the mapping function since lens distortion is not taken into account. After calling, the _valid state indicates whether or not the argument is inside the domain of the mapping function.
